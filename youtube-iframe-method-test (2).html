YouTube iframe 방식 비교 실험

API 플레이어와 일반 iframe 방식을 비교하는 실험 페이지야. 두 방식 모두 플레이어를 화면에 보이게 표시해. 이 페이지는 광고를 숨기거나 차단하지 않아.

1. 테스트할 영상 선택

검색 결과에서 영상 주소를 복사해 붙여넣어 줘.

2. 재생 방식

영상을 불러오면 이곳에 640×360 플레이어가 표시돼.

아직 영상을 불러오지 않았어.

일반 iframe은 실제 재생 시간이나 일시정지 상태를 페이지에 알려주지 않아. 영상의 재생/일시정지는 플레이어 안에서 직접 조작하고, 타이머는 재생을 시작한 뒤 별도로 눌러 맞춰 줘.

일반 iframe에서 앞뒤 이동은 start=초를 붙여 플레이어를 다시 불러오는 방식이야. 이때 버퍼링이 생길 수 있고, 광고가 다시 나올 수도 있어. 광고가 없어지는 방식은 아니야.

3. 테스트할 항목

  1. 같은 영상에서 두 방식을 각각 불러와 광고가 표시되는지 관찰.
  2. API 방식은 재생 위치 표시와 ±10초 이동이 실제 영상과 맞는지 확인.
  3. 일반 iframe 방식은 영상을 재생한 뒤 수동 타이머를 시작하고, ±10초 이동 후 위치가 얼마나 맞는지 확인.
  4. 일반 iframe 방식에서 탐색할 때 버퍼링·광고 재표시·타이머 오차가 발생하는지 기록.

YouTube 임베드 플레이어는 최소 200×200픽셀이어야 해. 숨김 1px 플레이어는 이 조건을 충족하지 않으므로 이 비교에는 넣지 않았어.

이 페이지는 실험용 프로토타입이야. 실제 광고 표시, 자동재생 허용 여부, 임베드 가능 여부는 영상·브라우저·YouTube 측 동작에 따라 달라질 수 있어.
