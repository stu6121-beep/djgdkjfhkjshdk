YouTube iframe 방식 비교 실험

API 플레이어와 일반 iframe을 비교하는 테스트야. 두 방식 모두 플레이어를 화면에 표시해. 광고를 숨기거나 차단하는 실험은 아니야.

1. 영상 선택

네 음악 검색 결과에서 영상 주소를 복사해 붙여넣어 줘.

2. 재생 방식

영상을 불러오면 640×360 플레이어가 표시돼.

아직 영상을 불러오지 않았어.

일반 iframe은 실제 재생 시간·일시정지 상태를 페이지에 알려주지 않아. 영상 안에서 재생/일시정지하고, 재생 시작 후 타이머를 별도로 맞춰 줘.

일반 iframe의 탐색은 start=초로 플레이어를 다시 불러와. 버퍼링이나 광고 재표시가 생길 수 있어. API를 안 쓴다고 광고가 사라지는 건 아니야.

3. 확인 항목

  1. 같은 영상에서 두 방식 모두 광고가 표시되는지 관찰.
  2. API 방식에서 시간 표시와 ±10초 탐색이 실제 재생과 맞는지 확인.
  3. 일반 iframe은 타이머를 직접 시작한 뒤 ±10초 탐색 후 위치 오차를 확인.
  4. 탐색할 때 버퍼링·광고 재표시·타이머 오차를 기록.
YouTube 임베드 플레이어의 최소 표시 영역은 200×200픽셀이야. 숨긴 1px 플레이어는 이 조건을 충족하지 않아 비교에 포함하지 않았어.

실제 광고·자동재생·임베드 가능 여부는 영상과 브라우저, YouTube 측 동작에 따라 달라져.
